# Privacy

job-search-os is a personal, single-user tool run by its owner (Muskan Nahata) on her own GitHub account.

- It accesses only the owner's own Gmail and Google Calendar, using an OAuth token she created, to read job-related replies, send her own application and follow-up emails, and book interview slots.
- Data is stored only in the owner's private database. Nothing is shared with, sold to, or used by anyone else.
- No other user is invited to this app. The owner can revoke access at any time at https://myaccount.google.com/permissions.
